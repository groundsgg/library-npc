# Model imports

The central documentation explains both supported import paths:

- [Import your own Blockbench model](https://docs.grounds.gg/reference/libraries/npc/importing).
- [Look up import options and supported features](https://docs.grounds.gg/reference/libraries/npc/api-reference#import-options).
- [Run imports through Gradle](https://docs.grounds.gg/reference/libraries/npc/advanced#run-imports-through-gradle).

Use matching NPC 2.0.0 modules. The [release downloads](https://github.com/groundsgg/library-npc/releases/tag/v2.0.0)
include the standalone CLI. Your runtime needs no importer when loading prepared content.
